Chip is the small pill for status tags and per-member actions.

Provide a lowercase label and a `tone`; pass `onClick` to make it a button.

- `action` marks an active status (voting), `highlight` a passive one (watching).
- `neutral` and `leave` are per-member actions (seat them, shoo). Keep them to the roster.
- Never use a chip as a page's main action. That is the primary Button.
